Downloading From Sites

In different sites you'll come across diferent formats. Some of them you can download directly with the browser (like ".mp4"), and some you can't (like ".m3u8"); you'll have to test each case to see if you're able to download. In the cases you can't download directly, you can use tools like yt-dlp (you can search to see how you can install them). The focus here will be how to get the URL of the video you want to download. Nedless to say that you don't need to do this in case a specific site don't block downloads. THIS TUTORIAL WILL BE UPDATED WHEN A SITE CHANGES, IF SOME METHODS IS NOT WORKING LET ME KNOW SO I CAN UPDATE.

  • PMVHaven (allows downloads with account only): Go to the video you want to download, Right Click -> View Page Source -> Control + F (search for terms like "contentURL" and ".mp4"). What you'll find is something similar to "https://pmvhavencloud.s3.eu-west-par.io.cloud.ovh.net/videos/[uploader-name]-[video-name].mp4/master.m3u8" (remove "/master.m3u8") or something similar to "videos\u002F[uploader-name]-[video-name].mp4" (add at the beginning the missing "https://pmvhavencloud.s3.eu-west-par.io.cloud.ovh.net" and replace every "\u002F" by "/"). The URL you'll get after doing this is something like "https://pmvhavencloud.s3.eu-west-par.io.cloud.ovh.net/videos/[uploader-name]-[video-name].mp4".
  • FapTap (doesn't allow downloads): Go to the video you want to download, Right Click -> View Page Source -> Control + F (search for terms like "content" and "vz"). What you'll find is something similtar to "https://vz-.../thumbnail.jpg" (replace "thumbnail.jpg" with "[resolution]/video.m3u8" where [resolution] is one of the resolutions available for the specific video). So, if a certain video's best resolution available is 1080p, you'd need the URL "https://vz-.../1080p/video.m3u8"
